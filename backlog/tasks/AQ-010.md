# AQ-010 : Ajouter la valeur absolue à la calculatrice

## Objectif

Fournir un nouveau changement petit et isolé afin de qualifier le chemin apply de la candidate AgentKit 1.5.1 sur une branche sans implémentation préalable.

## Comportement attendu

- Exporter `absolute(value)` depuis `src/calculator.mjs`.
- Retourner la valeur absolue pour un nombre fini positif, négatif ou nul.
- Lever `TypeError` pour les valeurs non numériques, `NaN` et les infinis.
- Ajouter des tests déterministes à `test/calculator.test.mjs`.
- Préserver la commande `npm run check`, les dépendances et `package-lock.json`.

## Critères de recette

1. Le plan OpenSpec décrit les cas positif, négatif, zéro et les valeurs rejetées.
2. `npm run check` réussit sous Node 26.13.0.
3. La phase apply publie un diff non vide sur la branche dédiée et met à jour une PR brouillon.
4. La CI indépendante valide le SHA publié avant toute fusion manuelle.

## Hors périmètre

Aucun changement de workflow, de dépendance, de configuration, de secret, de déploiement ou de la PR AQ-009. Aucun auto-merge ni retry payant.
